Assessment Tag and Attribute Patterns

Translate the wording of a question into the matching HTML syntax.

“Add a link”

Use a with href: <a href="about.html">About</a>

“Add an image”

Use img with src and descriptive alt: <img src="photo.jpg" alt="A mountain">

“Make the field compulsory”

Add the boolean required attribute: <input type="text" required>

“Give the field a name”

Add name; submitted form data uses this key: <input name="email">

“Create choices”

Use select and option for a dropdown. Radio buttons share a name; checkboxes can have independent names.

“Merge table cells”

Use colspan to merge columns and rowspan to merge rows.

Final check before submitting

  • Check that the requested tag is correctly opened and closed when required.
  • Check that every attribute is inside the opening tag.
  • Quote attribute values such as href="page.html".
  • Check exact matching values, especially label for and input id.
  • Do not use a button for navigation or a link for an action.
