HTML Assessment Quick Reference

Build checklist

  1. Start with <!DOCTYPE html> and <html lang="en">.
  2. Add charset, viewport, a useful title, and (when relevant) a description.
  3. Use headings in order and place content in semantic regions.
  4. Choose links for navigation and buttons for actions.
  5. Use meaningful alt text, labels, captions, and table scopes.
  6. Give controls names and validation attributes such as required or min.
  7. Check that every opening tag is closed and attributes are quoted.
  8. Test keyboard navigation and inspect the page with browser developer tools.

Common element groups

  • Structure: html head body title meta
  • Text: h1-h6 p br hr strong em code pre blockquote
  • Flow: header nav main section article aside footer
  • Media: a img figure figcaption
  • Lists: ul ol li dl dt dd
  • Data: table caption thead tbody tfoot tr th td
  • Forms: form label input select option textarea button fieldset legend

Common assessment requests

  • “Add a link” means <a href="...">...</a>.
  • “Add an image” means <img src="..." alt="..." />.
  • “Make this input compulsory” means add the boolean required attribute.
  • “Connect the label” means label for must equal input id.
  • “Send this field's value” means give the control a name.
  • “Create choices” means use select/option, radio inputs, or checkboxes.
  • “Merge table cells” means use colspan horizontally or rowspan vertically.
  • “Create a section link” means give the destination an id and use href="#id".
