# JavaScript Fundamentals

This track teaches the JavaScript language itself. Examples are short and
focused on syntax, values, objects, functions, and language features.

## Lessons

1. [`variables.js`](./variables.js) - declarations, values, and types
2. [`arrays.js`](./arrays.js) - creating and changing arrays
3. [`objects.js`](./objects.js) - object properties and access
4. [`functions.js`](./functions.js) - declarations, expressions, and callbacks
5. [`rest-parameters.js`](./rest-parameters.js) - collecting variable arguments
6. [`index.html`](./index.html) - a small browser entry point

After this track, continue with
[`data-structures-and-algorithms`](../data-structures-and-algorithms/).
