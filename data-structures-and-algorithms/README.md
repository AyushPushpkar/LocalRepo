# Data Structures and Algorithms

This track uses JavaScript to practice DSA concepts. The examples retain
side-by-side C++ comparisons where they clarify how a familiar operation maps
to JavaScript.

## Lessons

1. [`01-arrays.js`](./01-arrays.js) - array operations and complexity
2. [`02-functions.js`](./02-functions.js) - callbacks, comparators, and parameters
3. [`03-variables-and-data-types.js`](./03-variables-and-data-types.js) - values used in DSA code
4. [`04-maps-and-sets.js`](./04-maps-and-sets.js) - key-value and uniqueness lookups
5. [`05-stacks-and-queues.js`](./05-stacks-and-queues.js) - LIFO, FIFO, and efficient queues
6. [`06-built-in-methods.js`](./06-built-in-methods.js) - useful built-in operations

The overlap with `javascript-fundamentals` is deliberate: these lessons
revisit language features from an algorithmic perspective rather than
duplicating the introductory explanations.
